# Seedance Mirror

첨부한 이미지 생성 설치형 프로그램을 기능을 철저히 분석을 하고, 완벽히 똑같은 SaaS 플랫폼을 만들어줘! 기능적으로 완벽히 똑같고 차이는 로컬 프로그램이냐, 클라우드 환경을 이용하는 SaaS 플랫폼이냐의 차이야! 제작을 할 때 SaaS를 위한 부수적인 기능은 만들지마(로그인 등 관리 기능). API 연동해서 이미지가 잘 생성이 되면 나중에 필요한 기능을 추가할거야! 프롬프트를 입력하면 어떠한 편집이 없이 그대로 seedance API로 넘겨야하는게 핵심이야! 한글 버전으로 우선 만들어! 요약하자면 기능적으로 완벽하게 동일하게 만들어!  카피켓 프로그램이야!
